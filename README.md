# CrackIt — AI 压力面试模拟器

> 结合真实面经 + 你的简历，模拟高压面试场景，每轮给出逻辑、表达、方法论的精准反馈。

**🔗 在线体验：** [https://你的用户名.github.io/crackit](https://你的用户名.github.io/crackit)

---

## ✨ 功能特性

- **真实面经搜索** — 调用智谱 GLM web_search，自动搜索目标公司+岗位的高频面试题
- **简历结合提问** — 面试官读取你的简历，针对真实经历追问，不是泛泛而谈
- **每轮即时反馈** — 每次回答后立即给出：
  - 🔴 逻辑问题（因果缺失、论证不足）
  - 🟢 语言表达（用词模糊、结构混乱）
  - 🔵 方法论提升（STAR、MECE、漏斗拆解等）
  - ⭐ 优化示范（用更好的方式重新表达你的观点）
  - 📊 逻辑/表达双维评分（1-10分）
- **Demo 模式** — 无需 API Key，3轮预置对话完整体验交互
- **零依赖** — 纯单文件 HTML，下载即用，无需安装任何东西

## 🚀 快速开始

### 方式一：直接在线使用（GitHub Pages）
访问上方链接，无需任何配置。

### 方式二：本地使用
```bash
# 克隆仓库
git clone https://github.com/你的用户名/crackit.git

# 直接用浏览器打开
open index.html
```

### 获取 API Key
1. 访问 [open.bigmodel.cn](https://open.bigmodel.cn) 免费注册
2. 在控制台创建 API Key
3. 粘贴到页面的 API Key 输入框即可
